# LODE roadmap

## 0.1 — working foundation

CLI, manifest, SemVer resolution, static registry, ZIP packages, checksums, safe extraction, local store, tests, CI.

## 0.2 — registry operations

A dedicated registry repository, registry generator/validator, package metadata linter, automated release-to-index workflow, better lockfile synchronization.

## 0.3 — security

Signed artifacts, trusted keys, revocation, provenance, package quarantine, stronger archive limits.

## 0.4 — performance

Parallel downloads, persistent HTTP client, cache-aware no-op installs, atomic extraction, concurrent checksum verification.

## 1.0 — stable tool package manager

Documented package format, compatibility policy, migration policy, signed releases, reproducible release builds, Linux + Windows x86_64 support, optional ARM64 support, robust rollback/uninstall behavior, and a maintained public registry.
